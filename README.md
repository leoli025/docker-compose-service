<h1 align="center"><a href="https://github.com/leoli025/docker-compose-service" target="_blank">Docker Compose Service</a></h1>

## docker-compose 基础命令

```shell
# 在后台启动服务
docker-compose up -d

# 停止并删除服务
docker-compose down 

# 停止服务
docker-compose stop

# 重启服务
docker-compose restart

# 查看服务日志
docker-compose logs

# 查看启动的服务
docker-compose ps  
```
